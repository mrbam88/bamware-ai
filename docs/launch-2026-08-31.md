# Launch record — BrewDesk submitted to BOTH stores, 2026-08-31

27 days after Baat's 4.3(b) rejection: iOS 1.0 build 18 (App Store) and
Android build 8 (Play) submitted the same day. This doc is the durable
memory of how, and what it taught us. STATE.md has the day-by-day log;
this is the distilled version.

## The arc (Aug 4 → Aug 31)

1. **Baat rejected 4.3(b)** ("enough of these apps") — concept, not bugs.
   Strategy shift: differentiator must live IN the binary.
2. **BrewDesk repositioned** as an evidence-first WFH-spot finder:
   claim-level provenance, published methodology, honest unknowns. The
   transparency IS the product.
3. **Approval lane run as tickets** (#26–#33): reviewer simulation as a
   scripted test, degraded-state audit, privacy-claim verifier, cold-start
   snapshot, submission runbook. Every risk in the odds audit
   (docs in brewdesk) was closed with evidence except the untestable one.
4. **Flutter twin built to parity in one night** (12 tickets, worktree
   fan-out, supervisor QA), then polished (mockup-faithful UI, glass).
5. **Final week**: shelf animation rebuilt, map pixel-stilled, reviewer sim
   greened, launch screens, photo-rail regression found and fixed, store
   screenshots re-shot through a reusable fastlane lane, release-branch
   git flow codified, submitted.

## Decisions locked (with their why)

- **Accountless v1 everywhere; the store build gates the account surface
  out.** Bilal challenged it twice (didn't remember the gate; then argued
  thin-app risk) — held after review: 4.3(b) punishes SAMENESS, not
  simplicity, and a sign-in that unlocks nothing reads as padding. Accounts
  ship in v1.1 when community features make them real (bd#120; auth
  cold-start #7, token refresh #8, review-readiness bd#139 gate it).
- **Saved is never paywalled or account-walled** — local bookmarks free
  forever; Plus sells only server-backed things.
- **Release-branch flow** for store archives (committed flip, tags, no CLI
  overrides) — Bilal rejected invisible build-time switches.
- **Odds on record**: ~60–70% first pass, ~90%+ within two rounds;
  Resolution Center reply pre-written (bd#32 pack). A first rejection is a
  message, not a verdict.

## Engineering lessons (each cost us something)

- **iOS 26 tab identifiers attach late** → label-match tabs after launch
  (broke ReviewerSim, AccountFlow, StoreSurfaceGate suites the same way).
- **A map must never share layout with its overlays**: per-detent
  safeAreaPadding made the Map re-fit its camera every shelf drag. Chrome
  is constant; overlays move alone. (Quantified: 17 grey-levels/px churn →
  0.)
- **Sheets resize, never translate**: offset-based drags slide cards under
  bars; height-driven drags glued to the screen edge are the honest model.
  Crossfading swapped content needs a ZStack — VStack siblings shove the
  outgoing view out of the clip (the "flash").
- **Flutter FakeAsync**: real file I/O inside testWidgets never completes —
  sync fixture reads, injected fakes; never pumpAndSettle across an
  indeterminate spinner. A hung suite is a bug in the test.
- **NSPredicate CONTAINS is literal**; regex needs MATCHES. XCUITest a11y
  frames can lie (a grabber reporting the whole card) — press coordinates
  derived from the container, not the element's center.
- **Data joins need health counters** — the photo rail died silently for a
  week after a reseed rekeyed venues. Rule now in store-submission skill.
- **Screenshot rigs are tests**: pinning every localized string in the
  capture flow caught a missing es translation and stale marketing copy.
- **Screenshots need BOTH ASC sizes** (6.9" primary + 6.5" derived) — the
  6.5 slot hard-rejects 6.9 pixels.
- **Reviewer notes rot** — re-read against the current UI at every
  submission; ours pointed at deleted tabs.

## Process lessons

- **Foreground gates, still** — two more agents parked on background test
  monitors; one had to be taken over mid-hang. The night-supervisor rule
  survives contact again.
- **Supervisor QA with visual evidence works**: every UI merge this week
  shipped with emulator/simulator screenshots reviewed frame-by-frame; two
  agent bugs (truncated caption, personal email in a store binary) were
  caught only by looking.
- **Push back with the record, not memory**: the accountless defense held
  because the decision and its rationale were written down (STATE, tickets).
  Bilal agreed within one message both times.
- **Keep answers SHORT for Bilal** — he said it again, harder ("too much
  fluff... I can't read through all this"). One concept per message when
  he's confused. The confusion about the store gate existed because past
  summaries buried it.
